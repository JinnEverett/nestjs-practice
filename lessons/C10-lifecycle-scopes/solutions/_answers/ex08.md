# Đo DEFAULT vs REQUEST scope (mẫu — số liệu minh họa, máy dev, 1 lần đo)

## Dự đoán (viết trước khi đo)
Với endpoint đọc `GET /v1/_scope` (REQUEST) so với `GET /v1/products/1` (DEFAULT), tôi đoán REQUEST scope chậm hơn khoảng 20–40% về RPS ở 100 conns vì mỗi request phải dựng lại controller và các provider phụ thuộc.

## Kết quả
| kịch bản | conns | RPS | p99 ms |
|---|---|---|---|
| DEFAULT `/v1/products/1` | 10 | 9000 | 4 |
| DEFAULT `/v1/products/1` | 100 | 9500 | 30 |
| REQUEST `/v1/_scope` | 10 | 7000 | 6 |
| REQUEST `/v1/_scope` | 100 | 7300 | 42 |

## Giải thích
REQUEST scope làm Nest dựng lại instance của controller và mọi provider phụ thuộc cho mỗi request (constructor chạy mỗi lần, thêm áp lực GC). Chi phí tỉ lệ với số provider trong cây phụ thuộc bị "nổi" scope, nên chỉ dùng khi thật sự cần dữ liệu theo request.
