# ex05 · Giải thích

| Dòng | Output | Vì sao |
|---|---|---|
| A | `2026-10-01T00:00:00.000Z` | chuỗi **chỉ có ngày** được hiểu là UTC |
| B | `2026-09-30T17:00:00.000Z` | chuỗi có giờ nhưng **không offset** → hiểu theo TZ process (VN) → 00:00 VN = 17:00 UTC hôm trước |
| C | `9` | tháng trong `new Date(y, m, d)` / `getMonth()` tính từ 0 |
| D | `2` | 30/02/2026 tự tràn sang 02/03 (Date không báo lỗi!) |
| E | `{"at":"1970-01-01T00:00:00.000Z"}` | Date có `toJSON()` → chuỗi ISO |
| F | `string` | JSON.parse không biết chuỗi nào là ngày |
| G | `{"c":null,"d":[null]}` | key có giá trị `undefined`/function bị bỏ; trong mảng thì thành `null`; `NaN` → `null` |
| H | `TypeError` | BigInt không serialize được — cần `toJSON` riêng hoặc đổi sang chuỗi |
| I | `0.30 1.00` | `1.005` thật ra là `1.00499999…` trong nhị phân |
| J | `0 12 NaN` | `Number('')` là 0 (bẫy); khoảng trắng 2 đầu được bỏ; dấu `_` chỉ hợp lệ trong literal của code |
| K | `a|b||c` | `split` giữ phần tử rỗng giữa 2 dấu phẩy liền nhau |
