# ex01 · Giải thích

| Dòng | Output | Quy tắc |
|---|---|---|
| A | `An` | gọi qua `user.` → `this = user` |
| B | `TypeError` | gọi trần trong strict mode → `this = undefined` → đọc `undefined.name` |
| C, D | `Bình`, `Chi` | `call`/`apply` đặt `this` tường minh |
| E | `Dũng` | `bind` tạo hàm có `this` cố định |
| F, G | `Dũng` | hàm đã bind **không** bị `call` hay `bind` lần nữa đổi `this` |
| H | `undefined` | arrow không có `this` riêng → lấy `this` của module = `undefined` → `typeof` → `'undefined'` |
| I | `Hà` | `new` tạo object mới làm `this` |
| J | `TypeError` | `map` gọi callback trần (không có thisArg) → `this = undefined` |
| K | `Khoa` | tham số thứ 2 của `map` là `thisArg` |
