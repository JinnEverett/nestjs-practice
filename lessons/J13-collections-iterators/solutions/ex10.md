# ex10 · Giải thích

| Output | Vì sao |
|---|---|
| `C {"value":1,…}` | `next()` đầu tiên chạy tới `yield 1`; giá trị truyền vào lần next đầu bị bỏ (chưa có yield nào đang chờ) |
| `A nhận 5`, `D …10` | `next(5)` → biểu thức `yield 1` nhận 5 |
| `B finally`, `E … "xong" … done:true` | `return` kết thúc generator; `finally` chạy trước |
| `F {"done":true}` | generator đã xong |
| `G 1`, `B finally` | `break` gọi `return()` của iterator → `finally` chạy (chỗ dọn tài nguyên) |
| `A nhận undefined`, `B finally`, `H 1,NaN` | spread dùng `next()` không tham số → `a = undefined` → `undefined * 2 = NaN`; giá trị `return` không nằm trong kết quả spread |
| `I x,r` | `yield*` trả về giá trị `return` của generator con |
| `J 0 1 99 true` | `return(99)` kết thúc generator vô hạn từ bên ngoài |
