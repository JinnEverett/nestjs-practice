# ex04 · Giải thích

| Dòng | Vì sao |
|---|---|
| `A 2` | `1 + 1` |
| (không có B) | `throw` nhảy qua mọi `then` tới `catch` gần nhất |
| `C x2` | `catch` trả giá trị → chuỗi thành công trở lại với giá trị đó |
| `D x2` | `finally` không đổi giá trị (giá trị return của nó bị bỏ qua) |
| `F handled r` | tham số thứ 2 của `then` xử lý lỗi, chuỗi tiếp tục với giá trị trả về |
| `G lồng` | Promise lồng Promise được "làm phẳng" |
| `H thenable` | object có method `then` được đối xử như Promise |
| `I lần 1` | Promise chỉ settle một lần |
| `J undefined` | quên `return` → bước sau nhận `undefined` và không đợi promise bên trong |
| `K 0` | `Promise.all([])` resolve ngay với mảng rỗng |
| `L 5` | `throw` một giá trị không phải Error vẫn reject được (nhưng đừng làm vậy) |
