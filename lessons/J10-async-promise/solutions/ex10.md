# ex10 · Giải thích (thứ tự riêng của Node)

**Timer thứ nhất:**
- `A timeout` — callback timer.
- Sau mỗi callback, Node chạy hàng `process.nextTick` **trước**, rồi mới tới microtask Promise → `D nextTick`, `E promise`.
- Event loop đang ở phase **timers**; phase kế tiếp là **check** (setImmediate) → `C immediate` chạy trước…
- …timer lồng `B` (phải đợi vòng lặp sau quay lại phase timers).

**Timer thứ hai (50ms):**
- nextTick trước: `G nextTick`.
- Microtask theo thứ tự: `F promise`, callback của queueMicrotask (chỉ đặt thêm một nextTick H), `I promise 2`.
- Hàng microtask rỗng → Node kiểm tra lại hàng nextTick → `H`.

Bài học: `process.nextTick` có thể "bỏ đói" event loop nếu gọi đệ quy; code ứng dụng nên dùng `queueMicrotask`/Promise hoặc `setImmediate`. Chi tiết các phase ở N01.
