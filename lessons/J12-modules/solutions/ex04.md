# ex04 · Giải thích

| Output | Vì sao |
|---|---|
| `a.cjs chạy`, `A true 1` | `require` cache theo đường dẫn tuyệt đối: lần 2 trả cùng object, không chạy lại file |
| `B {"version":1}` | `exports` chỉ là biến trỏ tới `module.exports`; gán `exports = {...}` cắt liên kết, chỉ `version` đã gắn trước đó còn lại |
| `C {"name":"c"}` | ngược lại: thay `module.exports` bằng object mới → `exports.extra` gắn vào object CŨ, bị bỏ |
| `D string object` | CJS có `__dirname`, `module` |
| `F … false` rồi `E … true` | vòng require: `circ-y` nhận `exports` **chưa xong** của `circ-x` (loaded vẫn false) |
| `G x` | khi `circ-x` chạy xong, export đầy đủ |

Quy tắc: luôn dùng `module.exports = {...}` một lần ở cuối file.
