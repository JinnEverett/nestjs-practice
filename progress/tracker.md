- Trình độ khởi điểm JS/TS/Node:
- Mục tiêu: backend / phỏng vấn (từ SQL)
- Thời lượng mỗi buổi: 60–90 phút (từ SQL)
- Tần suất: hằng ngày (từ SQL). Dự kiến ~97 module + drill/case xen kẽ ≈ 4–5 tháng

- Máy: Windows 11, ổ C ít chỗ trống (kiểm tra trước khi sinh `shop_m`), Docker Desktop đã có (đang chạy container `sql-practice-pg` cổng 5433)
